# آزمون‌پلاس (Azmoon Plus)

سامانه آزمون آنلاین فارسی با رابط کاربری دارک نئونی، ثبت‌نام معلم، ساخت آزمون، کد اشتراک‌گذاری، شرکت دانش‌آموز و گزارش نتایج.

## امکانات
- تم تیره با رنگ‌های بنفش و آبی نئونی، واکنش‌گرا برای موبایل و دسکتاپ
- ثبت‌نام و ورود معلم با رمز عبور هش‌شده
- ساخت آزمون با سؤال‌های تستی و تشریحی و تعیین نمره
- کد اختصاصی برای هر آزمون
- ورود دانش‌آموز با نام و کد آزمون، ارسال پاسخ‌ها
- تصحیح خودکار تستی و علامت‌گذاری سؤال‌های تشریحی برای تصحیح دستی
- گزارش پاسخ‌ها و نمره‌های دانش‌آموزها
- ذخیره اطلاعات در فایل `data.json`

## نیازمندی‌ها
Node.js نسخه 18 یا بالاتر.

## اجرا روی کامپیوتر
1. Node.js را از https://nodejs.org نصب کنید.
2. فایل ZIP را استخراج کنید.
3. ترمینال را در پوشه پروژه باز کنید.
4. اجرا کنید:

   ```bash
   npm install
   npm start
   ```

5. در مرورگر باز کنید: http://localhost:3000
6. از «ورود معلم» وارد «ثبت‌نام معلم» شوید و حساب بسازید.

## تست نقش دانش‌آموز
پس از ساخت آزمون، کد آن را از بخش «آزمون‌های من» کپی کنید. می‌توانید در یک پنجره ناشناس یا دستگاه دیگر، سایت را باز کنید و از بخش «ورود دانش‌آموز» با نام و کد آزمون وارد شوید.

## انتشار روی اینترنت
برای استفاده از دستگاه‌های مختلف، پروژه را روی یک سرور Node.js یا سرویس میزبانی سازگار با Node مستقر کنید. مقدار `SESSION_SECRET` را به یک مقدار تصادفی و امن تغییر دهید و HTTPS را فعال کنید. پوشه/فایل داده باید روی دیسک دائمی باشد؛ برخی میزبان‌ها فایل‌های محلی را پس از استقرار یا راه‌اندازی مجدد پاک می‌کنند.

## نکات مهم پیش از استفاده واقعی در مدرسه
- این پروژه یک نسخه پایه و قابل اجراست؛ فایل JSON برای استفاده سبک و تک‌سروری است. برای مقیاس بالاتر، پایگاه داده‌ای مثل PostgreSQL توصیه می‌شود.
- ذخیره‌سازی فایل JSON تراکنش و قفل چندفرایندی ندارد؛ چند نمونه سرور را هم‌زمان با همین فایل اجرا نکنید.
- برای تولید، از session store دائمی (نه حافظه پیش‌فرض Express)، محدودسازی تلاش ورود، بکاپ، سیاست حفظ حریم خصوصی و کنترل دسترسی مدرسه استفاده کنید.
- تایمر سمت کاربر، جلوگیری از تقلب، محدودیت ارسال مجدد و تصحیح تشریحی خودکار در این نسخه پیاده‌سازی نشده‌اند.
- کد آزمون برای ورود کافی است؛ آن را فقط با شرکت‌کنندگان موردنظر به اشتراک بگذارید.
